## Usage

Open this repository folder as a vault in Obsidian. Each topic folder contains its lesson, exercise, and reference image. Follow the exercise instructions to practice in a separate solution vault.

Obsidian-specific features such as wikilinks, image embeds, colored highlights, and callouts are best viewed in Obsidian.
